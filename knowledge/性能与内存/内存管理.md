对象池、资源生命周期、内存泄漏排查

对象池：
对象池标准接口：
├── Get() / Spawn()          → 从池中取出一个可用对象
├── Recycle() / Despawn()    → 回收对象到池中
├── Prewarm(int count)       → 预创建指定数量（避免首次使用卡顿）
├── Clear()                  → 清空所有缓存（切场景时用）
└── Shrink()                 → 手动缩容（保留核心数量，释放多余的）

内存泄漏排查：
● 事件未取消订阅 → 对象被销毁但事件仍持有引用
● 静态引用不清理 → 静态列表里的对象永远不被 GC
● 对象池不回收 → 取出来用完忘记 Recycle
● 协程未停止 → 对象 Destroy 了但协程还在跑
● AB 包只加载不卸载 → 每 Load 一次内存多一份副本
