Delegate、Event、Action、Func 的区别与写法
概念	它是谁？	返回值要求	泛型参数 <T> 怎么理解？	游戏开发中的常见应用场景
Action	官方自带的、不图回报的委托	永远是 void (无返回值)	<T> 全是传入的参数！比如 Action<int, string>：传进一个数字和一个文本，干完活拉倒，不回传任何东西。	90% 的游戏事件！ 比如：玩家受伤(Action<int>)、游戏结束(Action)、按钮点击回调。
Func	官方自带的、必须给个交代的委托	必须有返回值！	最后一个 <T> 永远是返回值类型！比如 Func<int, bool>：传进一个 int，必须 return 一个 bool。	条件判断 / 获取数据！ 比如：判断怪物是否死亡(Func<bool>)、按 ID 获取装备属性(Func<int, ItemData>)。

C# 底层极其严格地规定：在使用 foreach 遍历任何集合（List、Dictionary）时，绝对不允许对这个集合进行增加或删除（Add / Remove）操作！
