● 内含碎片（把那些一句话原理全串联起来）： 什么是 DrawCall？-> 为了降 DrawCall，所以要打图集 (Atlas) -> 为了防止一个元素动导致全盘重绘，所以要动静分离 (Canvas拆分) -> 为了省 CPU，所以要把不需要点击的图关掉 Raycast Target。（你看，这就成了一套完整的 UI 优化连招！）
DrawCall：DrawCall 就是 CPU 呼叫 GPU 画画的次数。DrawCall 太高，CPU 会累死，游戏就会卡。 为了降低 DrawCall，减轻 CPU 的负担，UI 开发中必须把零碎的图片合并成图集。
【打图集（Sprite Atlas）】 = 减少 GPU 的渲染状态切换 = 降低 DrawCall。
【动静分离】 = 减少 CPU 的网格重建（Rebuild）计算量 = 降低 CPU 峰值卡顿。

网格重建：UGUI的底层逻辑会使它将同一画布下的UI元素合并成一个大网格，但是网格里如果有动态元素，那它的变化会导致整个网格所有的元素要重新参与合并网格的计算。

打图集 (Sprite Atlas)	动静分离 (嵌套 Canvas) 
降 DrawCall	降网格重建 (Rebuild)
