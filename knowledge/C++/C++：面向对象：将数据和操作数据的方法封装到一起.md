纯虚函数：包含至少一个纯虚函数的类成为抽象类，不能实例化（不能做形参/返回值），不能直接创建对象只能创建它的具体子类对象，只能作为基类被继承，用于定义接口规范，约定函数的入参，返回值和功能，不写实现。实现多态和接口隔离。函数体？
普通成员方法/成员函数：隶属于类，可访问私有成员。自带this指针（隐藏的指针常量函数，值为对象的内存地址，栈上）指向调用它的对象本身，可以访问所有成员变量。静态成员方法无this，只能访问静态成员变量和其他静态方法。
多态 ：“多态的底层是通过虚函数表和虚指针实现的。有虚函数的类会在编译期生成一张虚函数表vtable（只读数据段/常量区），表里存储所有虚函数的入口地址（函数指针）；每个对象的头部会有一个虚指针vptr，指向当前类的虚表。当用基类指针调用虚函数时，会先通过对象的虚指针找到对应虚表，再查表调用对应函数，最终调用哪个版本由对象的实际类型决定，以此实现运行时多态。

内存泄漏；定义：程序中动态分配的堆内存，在使用完毕后未被释放，导致这块内存既无法被再次使用，也无法被系统回收，持续占用内存空间。累积到一定程度会导致程序内存暴涨、卡顿甚至崩溃。

1. new / malloc 后没有对应的 delete / free
2. 异常分支跳过了内存释放语句
3. 指针重新赋值，导致旧堆内存的地址丢失（无人能再释放）
4. 循环引用导致智能指针无法正常析构
5. 资源句柄未关闭（文件、网络、协程等未正确销毁）

预防方法：

1. 配对使用 new/delete、malloc/free，遵循 “谁申请谁释放”
2. 使用 RAII 机制：std::unique_ptr、std::shared_ptr 等智能指针，对象析构时自动释放内存
3. 避免指针随意重定向，确保旧资源先释放再赋值
4. 借助内存检测工具（Valgrind、VS 内存诊断）定期排查
